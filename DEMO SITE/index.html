Bill of materials

What's inside

Three modules, one shared power rail. Everything talks to a single ESP32-S3 over SPI, I2C, and a parallel camera bus.

The board

ESP32-S3-WROOM-1

The brain — runs the UI, drives the camera, talks to Wi-Fi.

  • Dual-core LX7 @ 240MHz
  • 16MB flash / 8MB PSRAM
  • Built-in FPC camera connector
  • Dual USB-C, native USB flashing
The eye

OV2640 camera

Snaps a reference photo when a question needs one.

  • 2MP, 66° field of view
  • JPEG output over parallel DVP bus
  • Plugs into the board's FPC socket
  • No soldering required
The screen

2.8" SPI TFT + touch

A drawn keyboard for typing, and the space where answers land.

  • 240×320, ILI9341 driver
  • XPT2046 resistive touch
  • On-scren Keyboard, no physical keys
  • Shares one SPI bus with touch IC
The mind

Gemini 2.5 Flash

Reads the question — and the photo, if there is one — and writes back.

  • Multimodal: text + inline image
  • REST call over HTTPS, JSON body
  • Runs off-device, no local model
  • ~1–2s typical round trip
Request lifecycle

How a question becomes an answer

Four steps, start to finish — from a finger on glass to text back on screen.

01

Type or snap

Tap out a question on the on-screen keyboard. Flip the CAM toggle first if the question needs a photo.

touch input
02

Package the request

Firmware captures a JPEG if needed, base64-encodes it, and bundles it with the question text into one JSON body.

on-device
03

Ask Gemini

The board sends the request over HTTPS to Gemini's API, which reasons over the text and image together.

Wi-Fi · HTTPS
04

Show the answer

The reply is parsed out of the JSON response and word-wrapped straight onto the TFT.

on screen
